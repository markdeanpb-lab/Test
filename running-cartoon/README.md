# The Long Run

A pixel-art cartoon of Mark Dean's running career, written entirely in code: a 320×180 software framebuffer, a hand-drawn bitmap font, jointed runner sprites and an original chiptune soundtrack. It runs 4½ minutes, in 23 scenes, from a 26:21 first parkrun in Norwich (May 2016) to an 18:43 course PB at St Albans on 26 Sep 2026.

## Watch it

- `output/the-long-run.mp4`: the rendered video (1920×1080, 30 fps, with sound).
- `output/the-long-run.html`: the same cartoon as one self-contained page with play/pause, scrubbing, chapters and live chiptune. Open it in any browser.
- `index.html`: the development version of that page (loads the files in `src/` and `data/`).

## What's in it

Every time, place and quote comes from Mark's own records:

- **Strava**: 1,230 runs (9,199 km) logged between 14 May 2020 and 26 Sep 2026. Activity titles and descriptions supply the jokes: "Ouch my shins", "I have become death, destroyer of long runs", "The Wall Won", "Walk-to-the-end-of-my-street-with-crutches 2026 – 5:00 (New PB)".
- **parkrun**: all 186 results from [parkrunner 2425906](https://www.parkrun.org.uk/parkrunner/2425906/): 19 events, 40 course PBs, 5 podiums, PB 18:28.

The scenes, in order: title · Norwich 2016 and St Albans 2019 · lockdown London 2020 · Finsbury Park and the PB staircase · the 2022 race map · 2022 bloopers · track Tuesdays 2023 · Richmond Marathon in the heatwave · 100th parkrun on Christmas Day · the 2024 speed run · game over (the ankle, Valencia) · the comeback montage · moving to St Albans · St Albans 2025 · the St Albans Sixer · Manchester Marathon vs The Wall · the crutches PB · Japan · the puppy · the St Albans Claw · this morning's parkrun · high scores · credits.

A counter bar across the top tracks runs, kilometres and parkruns as of each scene's date, computed from the data files.

## Files

| Path | What it does |
|---|---|
| `data/strava-runs.txt` | Every Strava run: date and distance (rides, swims, walks and gym sessions left out, one duplicate recording removed). |
| `data/parkrun-results.json` | Every parkrun result, parsed from the parkrun profile page. |
| `data/career.js` | Generated by `tools/build-data.mjs`: totals, per-year kilometres, PB progressions, cumulative counters. |
| `src/engine.js` | Framebuffer, drawing primitives, 5×7 proportional font, sprites and the runner puppet (run, sprint, limp, crutches, ski, lift…). |
| `src/kit.js` | Scenery (London and St Albans skylines, parks, tracks, crowds, snow, fireworks) and UI (level banners, dialogue boxes, log cards, achievement toasts, HUD). |
| `src/scenes.js` | The 23 scenes and the timeline. |
| `src/audio.js` | Eight original chiptunes plus sound effects, played through WebAudio pulse, triangle and noise voices. The same event list plays live and renders offline for the video. |
| `src/player.js` | The page player, plus the `?render` mode that the video exporter drives. |
| `tools/build-page.mjs` | Inlines everything into `output/the-long-run.html`. |
| `tools/render-video.mjs` | Steps the cartoon frame by frame in headless Chromium, renders the soundtrack with an `OfflineAudioContext`, and encodes both with ffmpeg. |

## Rebuild

```bash
node tools/build-data.mjs                    # data/career.js from the two data files
node tools/build-page.mjs                    # output/the-long-run.html
FFMPEG=/path/to/ffmpeg node tools/render-video.mjs              # output/the-long-run.mp4
FFMPEG=/path/to/ffmpeg node tools/render-video.mjs --sheet 5,60,120 --out stills.png   # contact sheet
```

The video exporter needs Playwright with Chromium and an ffmpeg built with libx264 and AAC (`pip install imageio-ffmpeg` ships one; `python3 -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())"` prints its path).

Nothing here is wired into the St Albans Racing game in the rest of the repository; the folder stands alone.
